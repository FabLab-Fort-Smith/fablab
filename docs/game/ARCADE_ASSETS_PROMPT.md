# Arcade Game Asset Prompts

**Theme:** Cyberpunk, Hacker, Matrix, Neon Green on Black, Glitch aesthetic.
**Style:** Pixel Art or High-Contrast Vector.

## 1. Player Character ("The Runner")
*   **Description:** A hooded hacker figure or a stylized code avatar.
*   **Actions:**
    *   Running animation (side view).
    *   Jumping animation.
    *   Ducking/Sliding animation.
    *   "Glitch" effect when hit.
*   **Prompt Idea:** "Pixel art character, cyberpunk hacker running, neon green outlines, black background, side scrolling game sprite."

## 2. Obstacles
### A. The Virus (Ground Obstacle)
*   **Description:** A spiky, malicious-looking blob or bug.
*   **Prompt Idea:** "Pixel art computer virus monster, green and red, glitchy, dangerous, game sprite."

### B. The Firewall (Aerial Obstacle)
*   **Description:** A floating wall of flame or a red energy barrier.
*   **Prompt Idea:** "Pixel art firewall barrier, floating red digital flame, rectangular, game sprite."

## 3. Power-ups
### A. Shield
*   **Description:** A blue or white energy bubble/orb.
*   **Prompt Idea:** "Pixel art energy shield icon, glowing blue circle, protection powerup, game sprite."

### B. Score Multiplier (Data Packet)
*   **Description:** A computer chip, floppy disk, or glowing data cube.
*   **Prompt Idea:** "Pixel art computer chip, glowing gold or green, data packet, bonus item, game sprite."

## 4. UI Elements
*   **Heart/Life Icon:** Pixelated heart or battery meter.
*   **Cyberdeck Frame:** A border that looks like an old terminal screen.
